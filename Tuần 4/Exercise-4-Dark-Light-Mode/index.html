THEME SYSTEM

Dark / Light Mode

Đổi class trên thẻ body để kiểm tra hệ thống biến màu.

◐

Giao diện linh hoạt

Toàn bộ màu nền, chữ, đường viền và nút được điều khiển thông qua CSS Variables. Chuyển class dark-theme trên body thành light-theme để đổi sang giao diện sáng.

Bài thực hành: thử xóa class dark-theme trong thẻ body hoặc dùng nút để xem màu thay đổi.
