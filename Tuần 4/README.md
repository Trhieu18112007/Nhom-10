# Week 4 – Responsive Web Design

Bộ project gồm 4 hoạt động thực hành trên lớp (HD1–HD4) và 6 bài tập tự rèn luyện (Exercise 1–6), sử dụng HTML và CSS thuần.

## Cấu trúc thư mục

### Hoạt động thực hành
- `HD1-CSS-Variables`: Khai báo và sử dụng CSS Variables trong portfolio.
- `HD2-Responsive-Portfolio`: Portfolio hai cột trên desktop, một cột trên mobile.
- `HD3-Services-Breakpoints`: Lưới dịch vụ 4/2/1 cột theo kích thước màn hình.
- `HD4-Design-System`: Refactor màu sắc và khoảng cách thành biến CSS.

### Bài tập tự rèn luyện
- `Exercise-1-Typography`: Responsive Typography Scale.
- `Exercise-2-Adaptive-Card`: Product card thích ứng bằng Flexbox.
- `Exercise-3-Navigation`: Thanh điều hướng desktop/mobile.
- `Exercise-4-Dark-Light-Mode`: Giao diện sáng/tối bằng CSS Variables.
- `Exercise-5-Image-Gallery`: Gallery responsive dùng `auto-fit` và `minmax`.
- `Exercise-6-Contact-Form`: Form liên hệ theo hướng mobile-first.

- `ai_prompts.md`: Nhật ký prompt AI dùng để hỗ trợ từng bài.

## Cách chạy
Mở file `index.html` trong thư mục bài muốn xem bằng trình duyệt. Project dùng HTML/CSS thuần nên không cần cài thư viện hoặc chạy server.

## Kiểm tra responsive
Dùng DevTools của trình duyệt (F12) để thử các kích thước màn hình như 375px, 768px, 1024px và desktop.

## Lưu ý
- Thông tin liên hệ trong demo chỉ là dữ liệu ví dụ; hãy thay bằng thông tin của bạn nếu cần.
- Form liên hệ hiện là giao diện mẫu, chưa gửi dữ liệu đến email hoặc server.
