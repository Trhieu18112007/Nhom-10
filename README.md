# 🌐 Web Design Portfolio - Nhóm [Tên Nhóm]

Dự án này là trang Index Hub tổng hợp toàn bộ bài thực hành từ Tuần 1 đến Tuần 6 thuộc học phần **Thiết Kế Web (111101)**. Dự án tập trung vào việc áp dụng các kỹ thuật dàn trang hiện đại và tạo trải nghiệm người dùng (UX) mượt mà.

## 🚀 Công nghệ sử dụng
- **HTML5 & CSS3:** Sử dụng Semantics tags, CSS Grid (cho layout thẻ bài tập) và Flexbox (cho Sticky Footer).
- **CSS Checkbox Hack:** Kỹ thuật tạo Mobile Hamburger Menu không cần dùng đến JavaScript.
- **Thư viện AOS (Animate On Scroll):** Tích hợp hiệu ứng cuộn mượt mà với các tham số `data-aos-duration` và `data-aos-delay`.
- **W3C Validator:** Đảm bảo mã nguồn đạt chuẩn 100% không có lỗi cấu trúc.

## 💡 Top Prompts "Đắt giá" nhóm đã sử dụng với AI
Để hoàn thiện layout một cách nhanh chóng và chuẩn xác, nhóm đã sử dụng các cấu trúc prompt sau:

1. **Xử lý Sticky Footer:** 
   > *"Sử dụng CSS Flexbox, hãy viết cho tôi đoạn CSS để ép thẻ `<footer>` luôn luôn nằm dưới cùng của trình duyệt kể cả khi thẻ `<main>` ở giữa không có dữ liệu nào. Footer phải chia làm 3 cột responsive."*
2. **Animation Navigation Mobile:**
   > *"Tôi muốn làm một thanh Navigation. Trên Desktop nó là menu ngang. Trên Mobile màn hình < 768px, nó biến thành icon Hamburger. Hãy dùng kỹ thuật 'CSS Checkbox Hack' để khi bấm vào Hamburger, menu sẽ trượt mượt mà từ cạnh phải màn hình ra mà tuyệt đối không dùng Javascript."*
3. **Card Grid với Image Zoom:**
   > *"Viết một đoạn mã CSS Grid tạo layout chứa 6 thẻ Card. Trong mỗi thẻ có hình ảnh. Khi hover chuột vào Card, hình ảnh bên trong thẻ sẽ từ từ phóng to lên 1.1 lần nhưng không bị tràn ra ngoài khung Card, đồng thời hiện ra một nút bấm 'Xem chi tiết' ở giữa."*
