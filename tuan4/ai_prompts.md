## Bài 1 – Responsive Typography Scale
**Prompt:** Hãy thiết kế trang demo hệ thống cỡ chữ h1, h2, h3 và p bằng CSS Variables. Áp dụng Mobile First, mặc định cho màn hình nhỏ và dùng Media Queries từ 600px để tăng cỡ chữ. Giao diện hiện đại, có thẻ minh họa từng cấp chữ.

## Bài 2 – Adaptive Card Layout
**Prompt:** Tạo card sản phẩm hiện đại bằng HTML semantic và CSS Flexbox. Trên mobile, ảnh ở trên và nội dung ở dưới; từ 768px, ảnh bên trái và nội dung bên phải. Dùng CSS Variables, bo góc, bóng nhẹ và nút CTA.

## Bài 3 – Smart Navigation Bar
**Prompt:** Tạo trang demo thanh điều hướng responsive. Màn hình dưới 768px ẩn các liên kết và chỉ hiện nút Menu; màn hình lớn hiển thị toàn bộ liên kết. Dùng display: none, Flexbox và Media Queries. Không dùng JavaScript nếu đề chưa yêu cầu.

## Bài 4 – Dark/Light Mode Theme System
**Prompt:** Tạo trang minh họa Light Mode và Dark Mode bằng CSS Variables. Khai báo biến màu ở :root, ghi đè bằng body.dark-theme, thêm transition để chuyển màu mượt. Trình bày hai thẻ so sánh sáng/tối chuyên nghiệp.

## Bài 5 – Responsive Image Gallery
**Prompt:** Thiết kế thư viện ảnh responsive bằng CSS Grid với grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)). Sử dụng figure, img, figcaption; ảnh cùng chiều cao, thẻ bo góc, bóng nhẹ và tự xuống dòng.

## Bài 6 – Mobile-First Contact Form
**Prompt:** Tạo form liên hệ chuyên nghiệp gồm họ tên, email, chủ đề, nội dung và nút gửi. Trên mobile, form chiếm 100% chiều rộng khả dụng; trên desktop, giới hạn container và căn giữa. Dùng label liên kết với input, required, CSS Variables và Media Queries.

## Prompt cải tiến giao diện chung
**Prompt:** Hãy đồng bộ cả sáu bài bằng một design system gồm xanh dương chủ đạo, nền xám nhạt, card trắng, border nhẹ, border-radius, shadow tinh tế, typography rõ ràng và khoảng cách nhất quán. Ưu tiên Mobile First, không thêm JavaScript khi không cần thiết, giữ mã dễ đọc cho sinh viên mới học HTML/CSS.

## Kiến thức áp dụng
- CSS Variables để quản lý màu, cỡ chữ, khoảng cách và bóng.
- Mobile First và Media Queries để đáp ứng các kích thước màn hình.
- Flexbox cho card sản phẩm và thanh điều hướng.
- CSS Grid cho bố cục và thư viện ảnh.
- Semantic HTML5: header, nav, main, section, article, figure, footer, form.
- Focus state và reduced motion để cải thiện khả năng sử dụng.
