# CSS Responsive Homework – HDH Lab

Bộ bài tập gồm 6 trang HTML/CSS độc lập, trình bày theo phong cách hiện đại với xanh dương chủ đạo, nền sáng, card bo góc và responsive Mobile First.

## Cấu trúc
- `Exercise-01/`: Responsive Typography Scale
- `Exercise-02/`: Adaptive Card Layout
- `Exercise-03/`: Smart Navigation Bar
- `Exercise-04/`: Dark/Light Mode Theme System
- `Exercise-05/`: Responsive Image Gallery with CSS Grid
- `Exercise-06/`: Mobile-First Contact Form
- `ai_prompts.md`: Nhật ký prompt AI

## Cách chạy
1. Mở thư mục dự án bằng VS Code.
2. Mở `index.html` trong thư mục bài cần xem bằng trình duyệt hoặc Live Server.
3. Thay đổi kích thước cửa sổ để kiểm tra responsive.

## Ghi chú
- Bài 3 theo yêu cầu chỉ hiển thị/ẩn menu theo breakpoint; nút Menu chưa mở danh sách vì chưa dùng JavaScript.
- Bài 4: đổi hoặc xóa class `dark-theme` ở thẻ `<body>` để kiểm tra biến màu.
- Ảnh ở bài 5 cần kết nối Internet.
- Form bài 6 là giao diện mẫu, chưa kết nối backend để gửi dữ liệu.
